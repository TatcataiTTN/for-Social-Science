Pin down the RIGHT goal first — questions 2-4 below only make sense AFTER the goal is clear.

Second question

What is the scale of measurement of the DEPENDENT variable?

This question decides whether you take the PARAMETRIC or NON-PARAMETRIC branch — recalling the foundation from Module 01.

  • Nominal (gender, school type) → always non-parametric (chi-square).
  • Ordinal (a single Likert item, a ranking) → non-parametric (Mann-Whitney, Kruskal-Wallis, Spearman…).
  • Interval/ratio (test score, height, income) + meets parametric assumptions (Module 04: normal distribution, homogeneity of variance) → parametric.
  • Interval/ratio but VIOLATING parametric assumptions → consider switching to the corresponding non-parametric branch, even though the variable is originally interval/ratio.
Third question

If comparing groups: how many groups, independent or related?

  • 2 groups, INDEPENDENT (e.g. male/female, 2 different schools) — each person belongs to only 1 group.
  • 2 groups, RELATED (e.g. the same person measured at pretest then posttest) — paired by subject.
  • 3+ groups, INDEPENDENT (e.g. 3 schools A/B/C) — needs a post-hoc test if significant, since ANOVA/Kruskal-Wallis only says "there's a difference somewhere".
  • 3+ measurements, RELATED (e.g. 3 survey items on the same people) — repeated-measures ANOVA or Friedman.

Part 2 right after this looks up each case in detail with real data.

Fourth question

If measuring association: SYMMETRIC or DIRECTIONAL?

Only measuring the strength of association, no distinction of which variable is dependent → Correlation (Module 08). Want to build an equation predicting Y from X, clearly directional → Regression (Module 09).

Several observed variables at once, looking for latent structure: grouping VARIABLES → EFA; grouping OBJECTS → Cluster (Module 10) — details in Part 3.

PART 2/5
02

Comparing groups: how many groups, independent or related?

  • 2 independent groups, 2 related groups
  • 3+ independent groups, 3+ related measurements
  • Association between 2 nominal variables (crosstabs)
2 · 2 INDEPENDENT groups

Parametric: independent t-test · Non-parametric: Mann-Whitney

Real data (Module 05): comparing Math scores between 2 teaching methods (Project-based vs Traditional) — t(238)=7.59, p<0.001, very strongly significant.

If the dependent variable is ordinal (e.g. the single Likert item h1 by gender) instead of interval/ratio → Mann-Whitney U (Module 07); the real data gives U=6416, p=0.127 (NOT significant).

2 RELATED groups

Parametric: paired t-test · Non-parametric: Wilcoxon

The SAME group of subjects, measured TWICE (before/after an intervention) — quite different from 2 independent groups, in that each observation has its own "pair", not comparing 2 different sets of people.

Healthcare (illustrative): blood pressure of the same group of patients measured before and after 4 weeks of medication → paired t-test if parametric assumptions are met, Wilcoxon if not (e.g. a subjective pain scale that is ordinal).

3 · 3+ INDEPENDENT groups

Parametric: one-way ANOVA (+post-hoc) · Non-parametric: Kruskal-Wallis

Real data (Module 06): Math score across 3 schools A/B/C — F(2,237)=5.87, p=0.003, but eta²=0.047 is only a SMALL effect (recalling the Module 04 lesson: statistical significance ≠ a large effect size).

A Tukey post-hoc test shows EXACTLY which pair differs: A-B p=0.046, A-C p=0.0031 (significant), B-C p=0.427 (not) — ANOVA alone only says "there's a difference somewhere", not where.

3+ RELATED measurements

Parametric: repeated-measures ANOVA · Non-parametric: Friedman

An extension of the paired t-test when there are 3 or more conditions/measurements on the SAME group of subjects.

Real data (Module 07): comparing 3 anxiety rating items a1, a2, a3 on the same 240 students — Friedman χ²=0.555, p=0.758 (no difference at all, the 3 means are very close).

Association between 2 NOMINAL variables

Crosstabs → Chi-square

Real data (Module 07): gender × teaching method — χ²(1)=1.37, p=0.243, NOT significant (unlike the textbook example χ²=28.87 which was very strongly significant).

This is NOT "comparing groups" in the sense of means — both variables are nominal, so t-test/ANOVA can't be used, even though the question sounds similar.

03

Association & prediction

  • 2 continuous variables → correlation or regression?
  • Simple vs multiple regression, partial correlation
  • Multiple observed variables → EFA or Cluster?
3 · Association vs Prediction

Just MEASURING association, or PREDICTING with a direction?

Real data (Module 08): study hours and Math score — r=0.582, r²=0.338 — a strong, symmetric association, with no distinction of which variable "causes" the other.

Want to predict Y from X with a clear direction → switch to regression (next slide) — same underlying maths (r²=R² for one variable) but a different purpose: MEASURING association vs BUILDING a prediction equation.

Simple vs multiple regression

One predictor, or several at once?

Real data (Module 09): simple regression (study hours alone) gives R²=0.338 — identical to the Pearson r². Adding 2 more variables (interest h1, anxiety a1) → multiple regression: R²=0.495 (adjusted R²=0.488), F(3,236)=77.05, p<0.001.

Economics (illustrative): predicting house price not just from floor area (simple) but also from location + house age (multiple) — the same "controlling for each other" logic (ceteris paribus).

Partial correlation

Association between 2 variables AFTER removing a 3rd variable's effect

First-order partial correlation
rXY·Z = (rXY − rXZrYZ) / √[(1−rXZ²)(1−rYZ²)]

Healthcare (illustrative): an association between "coffee intake" and "blood pressure" may disappear once "smoking" (a confounding variable) is controlled for — see the partial correlation section in Module 08.

Multiple observed variables

Grouping VARIABLES or grouping OBJECTS?

Grouping variables (finding the latent concept behind several questions) → EFA. Grouping objects (finding similar profiles across several schools/people) → Cluster (Module 10) — two questions that sound alike but point in completely different directions.

Real data: EFA on 6 survey items → KMO=0.688, Bartlett χ²=313.28, p<0.001 (suitable for reduction into 2 latent factors: interest, anxiety).

Cluster — a real example

K-means on 195 PISA schools, k=2 statistically optimal

Silhouette k=2=0.252 (highest among k=2,3,4 tested) — but k=3 tells a clearer interpretive story ("compounding difficulty" vs "stable" vs "neutral" clusters).

Agriculture (illustrative): grouping 500 plots of land by 5 soil indicators (pH, moisture, N-P-K...) into 3 clusters "good/average/needs improvement" soil — the same Cluster logic, a completely different domain.

Integrated case studies

Scenario 1

"Do Math scores differ across Schools A, B, and C?"

The dependent variable (Math score) is a ratio scale, approximately normally distributed (Module 04), 3 INDEPENDENT groups.

→ One-way ANOVA (Module 06) — real result: F(2,237)=5.87, p=0.003, Tukey identifies School A as different from B and C.

Scenario 2

"For the same 240 students, does the score increase from pretest to posttest?"

The SAME subjects, measured TWICE (before/after) — not two different sets of people.

→ Paired t-test (Module 05), if the score meets parametric assumptions.

Scenario 3

"Does the h1 rating (Likert) differ across 3 schools?"

The dependent variable is a single Likert item → ORDINAL scale, not interval/ratio. 3 independent groups.

→ Kruskal-Wallis (Module 07) — real data: H=2.844, p=0.241, NOT significant.

Scenario 4

"How are study hours and Math score associated, and how is that used to predict?"

Needs BOTH measuring the association AND directional prediction — two complementary steps, not substitutes.

→ Pearson r (Module 08, r=0.582) to measure the association, then linear regression (Module 09, R²=0.338) to build a prediction equation.

Scenario 5

"Do the 6 survey items really measure 2 different psychological concepts?"

A question about the latent STRUCTURE behind several observed VARIABLES, not about comparing groups.

→ EFA (Module 10) — KMO=0.688, Bartlett p<0.001, 2 factors "rediscover" the exact 2 concepts the items were designed around.

Scenario 6

"Can the 195 PISA schools be grouped into different profile types?"

A question about grouping OBJECTS (schools), not grouping variables.

→ K-means cluster analysis (Module 10) — Silhouette k=2=0.252 is statistically optimal, k=3 is easier to interpret.

Warning

Don't choose a test AFTER you've already seen the result

"Running several tests and picking whichever gives p<0.05" is a form of p-hacking — the test must be chosen BASED ON the research question and the scale of measurement, decided BEFORE looking at the result.

1. Decision tree: 4 questions leading to the right method

All 8 inferential statistics modules (03-10) can be summarised into 4 sequential questions. Answering these 4 questions in order almost always leads to the correct method.

  1. What is your goal? Describe one variable (Module 03) · Compare means/ranks between GROUPS (Modules 05-07) · Measure ASSOCIATION between 2 continuous variables (Module 08) · PREDICT one variable from other(s) (Module 09) · Find a latent structure across MULTIPLE variables/objects (Module 10).
  2. What is the scale of measurement of the main variable (usually the dependent variable)? Nominal/ordinal → NON-PARAMETRIC branch. Interval/ratio + meets parametric assumptions (Module 04: normal distribution, homogeneity of variance...) → PARAMETRIC branch.
  3. If comparing groups: how many groups, and are they INDEPENDENT or RELATED (measured on the same subjects)? 2 independent groups / 2 related groups / 3+ groups — each case has its own corresponding parametric AND non-parametric test.
  4. If measuring association: do you need SYMMETRIC (no distinction of which variable is dependent) or DIRECTIONAL (predicting Y from X)? Symmetric → correlation. Directional, 1 independent variable → simple regression. Directional, several independent variables → multiple regression.

3. Practice: 6 real scenarios, choosing the right method

Uses the EXACT research questions that have appeared throughout Modules 03-10 — cover up the "answer" and try to answer for yourself first.

Scenario 1: "Does the mean Math score differ between School A, B, and C?" — the dependent variable (Math score) is a ratio scale, approximately normally distributed (checked in Module 04), 3 INDEPENDENT groups.

→ Answer: One-way ANOVA (+ Tukey post-hoc if significant) — Module 06.

Scenario 2: "For the same 240 students, does the score increase from pretest to posttest?" — the SAME subjects, measured 2 TIMES.

→ Answer: Paired t-test (if the score meets parametric assumptions) — Module 05.

Scenario 3: "Does the h1 rating (1-5 Likert scale) differ across 3 schools?" — the dependent variable is a Likert scale (ORDINAL, not interval/ratio), 3 independent groups.

→ Answer: Kruskal-Wallis (non-parametric, since a single Likert item is ordinal) — Module 07.

Scenario 4: "Are study hours and Math score associated, and how is that association used to PREDICT the Math score of a new student?" — needs BOTH measuring the association AND directional prediction.

→ Answer: start with Pearson r (Module 08) to measure the association, then linear regression (Module 09) to build a prediction equation — two complementary steps, not substitutes for each other.

Scenario 5: "Do the 6 survey items (h1-h3, a1-a3) really measure 2 different psychological concepts (interest, anxiety), or do they actually measure 1 shared concept?" — a question about the latent STRUCTURE behind several observed VARIABLES.

→ Answer: Exploratory factor analysis (EFA) — Module 10.

Scenario 6: "Can the 195 PISA schools be grouped into types with different difficulty/advantage profiles?" — a question about grouping OBJECTS (schools), not grouping variables.

→ Answer: K-means cluster analysis — Module 10.

The most common overall trap across all 8 modules: confusing an ORDINAL scale (a single Likert item) with an INTERVAL/RATIO scale (a summed score across several Likert items, or a test score) — leading to the wrong parametric/non-parametric branch. ALWAYS go back to Module 01 to determine the correct scale of measurement BEFORE choosing a test, don't choose the test first and then try to "force" the data to fit.
