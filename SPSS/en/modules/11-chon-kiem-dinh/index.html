1. Decision tree: 4 questions leading to the right method

All 8 inferential statistics modules (03-10) can be summarised into 4 sequential questions. Answering these 4 questions in order almost always leads to the correct method.

  1. What is your goal? Describe one variable (Module 03) · Compare means/ranks between GROUPS (Modules 05-07) · Measure ASSOCIATION between 2 continuous variables (Module 08) · PREDICT one variable from other(s) (Module 09) · Find a latent structure across MULTIPLE variables/objects (Module 10).
  2. What is the scale of measurement of the main variable (usually the dependent variable)? Nominal/ordinal → NON-PARAMETRIC branch. Interval/ratio + meets parametric assumptions (Module 04: normal distribution, homogeneity of variance...) → PARAMETRIC branch.
  3. If comparing groups: how many groups, and are they INDEPENDENT or RELATED (measured on the same subjects)? 2 independent groups / 2 related groups / 3+ groups — each case has its own corresponding parametric AND non-parametric test.
  4. If measuring association: do you need SYMMETRIC (no distinction of which variable is dependent) or DIRECTIONAL (predicting Y from X)? Symmetric → correlation. Directional, 1 independent variable → simple regression. Directional, several independent variables → multiple regression.

3. Practice: 6 real scenarios, choosing the right method

Uses the EXACT research questions that have appeared throughout Modules 03-10 — cover up the "answer" and try to answer for yourself first.

Scenario 1: "Does the mean Math score differ between School A, B, and C?" — the dependent variable (Math score) is a ratio scale, approximately normally distributed (checked in Module 04), 3 INDEPENDENT groups.

→ Answer: One-way ANOVA (+ Tukey post-hoc if significant) — Module 06.

Scenario 2: "For the same 240 students, does the score increase from pretest to posttest?" — the SAME subjects, measured 2 TIMES.

→ Answer: Paired t-test (if the score meets parametric assumptions) — Module 05.

Scenario 3: "Does the h1 rating (1-5 Likert scale) differ across 3 schools?" — the dependent variable is a Likert scale (ORDINAL, not interval/ratio), 3 independent groups.

→ Answer: Kruskal-Wallis (non-parametric, since a single Likert item is ordinal) — Module 07.

Scenario 4: "Are study hours and Math score associated, and how is that association used to PREDICT the Math score of a new student?" — needs BOTH measuring the association AND directional prediction.

→ Answer: start with Pearson r (Module 08) to measure the association, then linear regression (Module 09) to build a prediction equation — two complementary steps, not substitutes for each other.

Scenario 5: "Do the 6 survey items (h1-h3, a1-a3) really measure 2 different psychological concepts (interest, anxiety), or do they actually measure 1 shared concept?" — a question about the latent STRUCTURE behind several observed VARIABLES.

→ Answer: Exploratory factor analysis (EFA) — Module 10.

Scenario 6: "Can the 195 PISA schools be grouped into types with different difficulty/advantage profiles?" — a question about grouping OBJECTS (schools), not grouping variables.

→ Answer: K-means cluster analysis — Module 10.

The most common overall trap across all 8 modules: confusing an ORDINAL scale (a single Likert item) with an INTERVAL/RATIO scale (a summed score across several Likert items, or a test score) — leading to the wrong parametric/non-parametric branch. ALWAYS go back to Module 01 to determine the correct scale of measurement BEFORE choosing a test, don't choose the test first and then try to "force" the data to fit.
