1. Simple linear regression

Simple linear regression builds a straight line that predicts the value of the DEPENDENT variable (Y) from ONE INDEPENDENT variable (X) — unlike correlation (Module 08), it has a clear direction: X predicts Y, not the other way around (see Module 08 section 5 on the asymmetry of regression).

Simple regression equation
Ŷ = a + b·X
  • Ŷthe PREDICTED value of Y (not the observed real value)
  • aintercept — the predicted Ŷ when X=0
  • bslope — how much Y changes when X increases by 1 unit
Real data (n=240): math = 35.58 + 2.51 × study_hours. The slope b=2.51 (SE=0.228, t=11.03, p<0.001, 95%CI=[2.06, 2.96]) matches exactly the figure computed in Module 08 when discussing slope asymmetry. R²=0.338 — identical to the Pearson r² from Module 08 (because simple regression and Pearson correlation share the same underlying computation, only presented differently).
A student with study_hours=0 has a predicted maths score of 35.58 — is that practically meaningful? In this data, the lowest study_hours actually observed is 0.5 hours — no student truly studied 0 hours. The intercept a is only mathematically meaningful (the Y-axis crossing point); interpreting it in real-world terms (extrapolating beyond the observed data range) needs great caution.

2. Multiple regression

Multiple regression extends the same idea to SEVERAL independent variables at once — answering: "after accounting for the effect of the other variables, how much does this particular X still contribute?"

Multiple regression equation
Ŷ = a + b₁X₁ + b₂X₂ + ... + bₖXₖ
  • b₁, b₂, ...each independent variable's own slope — each b measures that variable's effect while HOLDING all other variables in the model constant (ceteris paribus)
  • kthe number of independent variables in the model
Real data — model math ~ study_hours + h1 + a1 (n=240):

R²=0.495 (adjusted R²=0.488), F(3,236)=77.05, p<0.001 — the model is statistically significant overall, and ALL 3 independent variables have a significant individual contribution. ✅ Verified to match 100% between Python (statsmodels) and PSPP (the REGRESSION command).
Comparison with the simple regression in section 1: the coefficient of study_hours drops only slightly from 2.51 (simple) to 2.49 (multiple) — almost unchanged, because study_hours has little correlation with h1/a1 (see VIF in section 4). If two independent variables correlate strongly with each other, the B coefficient can change A LOT when a variable is added or removed from the model — always check VIF before trusting B.
How does adjusted R² differ from ordinary R²? Ordinary R² ALWAYS increases (never decreases) when you add a variable to the model, even a meaningless one — adjusted R² "penalizes" adding variables, only increasing if the new variable genuinely improves the model enough. Here R²=0.495 and adjusted R²=0.488 are quite close — a good sign, no "redundant" variable in the model.

3. Standardized regression coefficients (Beta) — comparing which variable "matters" more

Raw B coefficients CANNOT be compared directly between variables with different measurement units — B(study_hours)=2.49 means "2.49 maths points per HOUR of study", while B(h1)=2.15 means "2.15 maths points per POINT on the 1-5 Likert scale" — two completely different units, so you cannot say the larger B is "more important".

Standardized Beta coefficient
β = b × (SD of X / SD of Y)
  • βthe regression coefficient after both X and Y are standardized to the same "number of standard deviations" (z-score) scale — no longer tied to the original measurement units, so comparable across variables
Real data: β(study_hours)=0.577; β(h1)=0.229; β(a1)=−0.297. Even though B(study_hours)=2.49 is only slightly larger than B(h1)=2.15 in raw terms, β shows study_hours is FAR stronger (0.577 vs. 0.229 and −0.297) — because study_hours has a very different spread (SD) than the 1-5 Likert scale. Correct conclusion: study hours is the STRONGEST predictor among the 3 variables, in standardized terms.
A common trap: comparing raw B coefficients directly to conclude "which variable matters more" when the independent variables are measured in different units — this is a common interpretation error. Always use standardized Beta for comparing RELATIVE importance; use raw B for PREDICTING actual values (since raw B keeps the original unit, easy to interpret in context).

4. Regression assumption checks

Regression results are only trustworthy when 4 key assumptions hold — serious violations can make the B coefficients and p-values WRONG, not merely less precise.

Variance Inflation Factor (VIF)
VIF(Xᵢ) = 1 / (1 − R²ᵢ)
  • R²ᵢthe R² from regressing THIS variable Xᵢ on ALL the other independent variables in the model — a high R²ᵢ means Xᵢ is almost "duplicating information" already present in the other variables
  • High VIF(usually >5 or >10 depending on convention) → serious multicollinearity, the B coefficient becomes UNSTABLE (swings wildly when one observation is added or removed)
Why is multicollinearity dangerous? If 2 independent variables measure almost the SAME thing (e.g. two questions asking essentially the same content), the model cannot "decide" which one to credit with the effect — the B coefficients for both can become meaningless (even flipping sign against logic) even though the overall model (R², F) still looks fine. This is why you MUST check VIF before interpreting EACH individual B coefficient.

  1. Transform → Compute Variable... → Target=study_hours, Numeric Expression=study_hours / 10 → If... → condition study_hours > 20 → OK.

A. Multiple regression:

  1. File → Open → Data... → select lop_hoc_240.sav.
  2. Analyze → Regression → Linear...
  3. Send math to the Dependent box; send study_hours, h1, a1 to the Independent(s) box.

📜 Theoretical Background

Linear regression traces back to Francis Galton's work in the late 19th century studying the heights of parents and children (he called it "regression toward mediocrity" — the children of very tall parents tended to be shorter than their parents, "regressing" toward the average). Karl Pearson later formalized this with rigorous mathematics, on the same foundation as the correlation coefficient r learned in Module 08 — which is why the R² of simple regression ALWAYS equals the r² of the Pearson correlation between exactly those 2 variables.
