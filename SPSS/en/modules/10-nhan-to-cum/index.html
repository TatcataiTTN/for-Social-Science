1. Exploratory Factor Analysis (EFA)

EFA answers the question: can a set of MANY observed variables (survey questions, items) be reduced to a SMALL number of latent factors/constructs — and which variable "belongs to" which latent factor?

Before running EFA — 2 mandatory checks:
CheckWhat it answersReal result (h1-h3, a1-a3, n=237)
KMO (Kaiser-Meyer-Olkin)Is there enough shared correlation among the variables to make factoring "worthwhile"? (0-1, higher is better)KMO=0.688 ("mediocre" — acceptable, not excellent)
Bartlett's testDoes the correlation matrix differ significantly from an identity matrix (i.e. the variables being completely uncorrelated)?χ²=313.28, p<0.001 → significant, data suitable for EFA
Factor loading
λᵢⱼ = correlation between observed variable i and latent factor j
  • λᵢⱼruns from −1 to 1, like a correlation coefficient — |λ|≥0.4 or ≥0.5 is usually considered a "clear" loading on that factor (exact threshold varies by field)
  • Communality (h²)the sum of squared loadings of a variable across ALL factors — the % of that variable's variance "explained" by the factors

Eigenvalues: F1=2.21, F2=1.73 (both >1 by Kaiser's criterion). Total variance explained ≈65.7%. EFA "rediscovers" exactly the 2 latent concepts (interest, anxiety) that were used to GENERATE this dataset — confirming the method works correctly: items h1-h3 load clearly onto one factor, a1-a3 onto the other, with no mixing.
PCA (Principal Component Analysis) and EFA (Factor Analysis) are NOT the same technique, though often confused. PCA (SPSS/PSPP's default, called EXTRACTION=PC) finds linear combinations that explain the MAXIMUM observed variance — without distinguishing "common" variance from each variable's "unique" (error) variance. "True" EFA (principal axis, maximum likelihood...) models only the COMMON variance, assuming each variable has its own measurement error — closer to the idea of a "latent concept". With clearly structured data like this, both give similar results; with messier data, choosing the wrong technique can lead to different conclusions.

2. Cluster Analysis

Cluster analysis answers a question completely DIFFERENT from EFA: instead of grouping VARIABLES together, clustering groups the OBSERVED OBJECTS (here, 195 schools) into groups with similar PROFILES across several variables at once.

Easy trap: "factor analysis" and "cluster analysis" sound similar (both "group" something) but grouping OBJECTS is completely different from grouping VARIABLES. EFA answers "which ITEMS measure the same concept?"; Cluster answers "which SCHOOLS have similar profiles?".

Silhouette score (measures clustering quality)
s(i) = (b(i) − a(i)) / max(a(i), b(i))
  • a(i)average distance from point i to the OTHER points in the SAME cluster
  • b(i)average distance from point i to the points in the NEAREST other cluster
  • s(i)runs from −1 to 1; close to 1 = good clustering (close to own cluster, far from others); close to 0 = fuzzy boundary; negative = possibly mis-assigned
Real verification: PSPP (QUICK CLUSTER) and Python (scikit-learn KMeans) give DIFFERENT cluster sizes on the SAME data, same k=3! PSPP: 37/128/30. Python: 64/49/82. This is NOT a bug — K-means is very SENSITIVE to its initial centroids, and the two software packages use different initialization strategies. This is precisely why good practice is to run K-means MULTIPLE TIMES with different random initializations (Python's default `n_init=10` — 10 runs, keeping the best) before trusting the final result, rather than running once and treating it as "the truth".

3. Introduction to SEM and Multilevel Modeling

SEM (Structural Equation Modeling) combines the idea of EFA (a latent variable measured by several observed variables) AND regression (Module 09) in a SINGLE model — allowing simultaneous testing of "do the items really measure the intended latent concept" (measurement) AND "how do the latent concepts causally relate to each other" (structure). This is an advanced technique requiring dedicated software (AMOS, Mplus, lavaan in R) — basic PSPP and SPSS do NOT support it.

Why does PISA data need a MULTILEVEL (HLM) model, not just ordinary regression? The 7,368 students in the PISA dataset are NESTED WITHIN 195 schools — students in the SAME school tend to be more similar to each other than to students in other schools (same teachers, same facilities). Ordinary regression (Module 09) assumes INDEPENDENT observations — this assumption is VIOLATED when data has a nested structure, causing standard errors (SE) to be UNDERESTIMATED, which easily leads to falsely concluding "statistical significance" (increased Type I error). A multilevel model separates variance at the student level and the school level, handling this nested structure correctly.

SEM and multilevel models are beyond the direct computational scope of this course (they require dedicated software/libraries beyond basic SPSS/PSPP) — this section only introduces the concepts and points out the right kind of data situation (like PISA) where they should be considered.

4. SPSS/PSPP Practice

🖱️ Step-by-step mouse clicks in SPSS:

A. Factor analysis (EFA):

  1. File → Open → Data... → select lop_hoc_240.sav.
  2. Analyze → Dimension Reduction → Factor...
  3. Send h1, h2, h3, a1, a2, a3 to the Variables box.
  4. Click Descriptives... → check KMO and Bartlett's test of sphericity → Continue.
  5. Click Extraction... → choose Fixed number of factors = 2 → Continue.
  6. Click Rotation... → choose Varimax → Continue → OK.

B. Cluster analysis (K-means):

  1. Open vnm_truong_195_tong_hop.sav.
  2. Analyze → Classify → K-Means Cluster...
  3. Send EDULEAD, NEGSCLIM, STAFFSHORT, EDUSHORT, DIGPREP to the Variables box, set Number of Clusters = 3.
  4. Click OK — read the "Final Cluster Centers" and "Number of Cases in each Cluster" tables.

PSPP equivalent (confirmed to run — see pspp/10_nhan_to_cum_en.sps):

FACTOR VARIABLES=h1 h2 h3 a1 a2 a3
  /EXTRACTION=PC
  /CRITERIA=FACTORS(2)
  /ROTATION=VARIMAX.

QUICK CLUSTER EDULEAD NEGSCLIM STAFFSHORT EDUSHORT DIGPREP
  /CRITERIA CLUSTER(3)
  /PRINT INITIAL.
* Note: PSPP uses EXTRACTION=PC (Principal Component), which differs
* from the "principal axis factoring" typically used in Python -
* the qualitative conclusion (same 2 variable groups) is the same but
* the loadings are not 100% identical. QUICK CLUSTER gives different
* cluster sizes than Python due to different K-means initialization
* strategies (see the warning in section 2).
