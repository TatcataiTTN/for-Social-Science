1. 简单线性回归

简单线性回归建立一条直线，用ONE个自变量（X）来预测因变量（Y）的值——不同于相关关系（第08单元），它具有明确的方向：X预测Y，而不是反过来（参见第08单元第5节关于回归不对称性的讨论）。

简单回归方程
Ŷ = a + b·X
  • ŶY的预测值（不是实际观测到的真实值）
  • a截距（intercept）——当X=0时Ŷ的预测值
  • b斜率（slope）——X每增加1个单位，Y变化多少
真实数据（n=240）：math = 35.58 + 2.51 × study_hours。斜率b=2.51（SE=0.228, t=11.03, p<0.001, 95%CI=[2.06, 2.96]）与第08单元讨论斜率不对称性时计算出的数值完全一致。R²=0.338——与第08单元Pearson r的r²完全相同（因为简单回归与Pearson相关分析共用同一套底层计算，只是呈现方式不同）。
study_hours=0的学生，预测数学成绩为35.58——这有实际意义吗？在本数据中，实际观测到的最低study_hours是0.5小时——没有任何一名学生真正学习0小时。截距a只有数学意义（Y轴截点），若要按实际含义解读（外推到观测数据范围之外），需要非常谨慎。

2. 多元回归

多元回归把上述思路扩展到同时使用MULTIPLE个自变量——回答的问题是："在控制了其他变量的影响之后，这个X变量还能额外贡献多少？"

多元回归方程
Ŷ = a + b₁X₁ + b₂X₂ + ... + bₖXₖ
  • b₁, b₂, ...各自变量各自的斜率系数——每个b衡量该变量在模型中保持所有其他变量不变时的影响（其他条件不变原则）
  • k模型中自变量的数量
真实数据——模型 math ~ study_hours + h1 + a1（n=240）：
变量BSEtp
（常数）37.232.1017.76<0.001
study_hours（学习时长）2.490.2012.43<0.001
h1（兴趣，1-5量表）2.150.444.91<0.001
a1（焦虑，1-5量表）−2.680.42−6.36<0.001
R²=0.495（调整后R²=0.488），F(3,236)=77.05, p<0.001——模型整体具有统计显著性，且三个自变量各自的贡献均显著。✅ 已验证Python（statsmodels）与PSPP（REGRESSION命令）结果100%一致。
与第1节简单回归的比较：study_hours的系数从2.51（简单回归）略降至2.49（多元回归）——几乎不变，因为study_hours与h1/a1的相关性很弱（参见第4节的VIF）。如果两个自变量之间相关性较强，添加或删除变量时B系数可能出现大幅变化——因此在信任B系数之前，务必先检查VIF。
调整后R²（Adjusted R²）与普通R²有何不同？普通R²在添加变量后总是会上升（不会下降），即使该变量毫无意义——调整后R²会对添加变量进行"惩罚"，只有当新变量确实充分改善模型时才会上升。此处R²=0.495与调整后R²=0.488相当接近——这是好现象，说明模型中没有"多余"的变量。

3. 标准化回归系数（Beta）——比较哪个变量"更重要"

原始B系数无法在测量单位不同的变量之间直接比较——B(study_hours)=2.49意味着"每多学1小时，数学多2.49分"，而B(h1)=2.15意味着"李克特1-5量表每多1分，数学多2.15分"——两者单位完全不同，不能仅凭B的大小判断哪个"更重要"。

标准化Beta系数
β = b × (X的SD / Y的SD)
  • β将X和Y都标准化为同一"标准差数量"（z分数）尺度后得到的回归系数——不再受原始测量单位影响，可在变量间比较
真实数据：β(study_hours)=0.577；β(h1)=0.229；β(a1)=−0.297。尽管原始B(study_hours)=2.49只是略高于B(h1)=2.15，但β显示study_hours的影响明显更强（0.577 相对于 0.229 和 −0.297）——因为study_hours的离散程度（SD）与1-5李克特量表截然不同。正确结论：以标准化单位衡量，学习时长是三个变量中最强的预测因子。
常见陷阱：当自变量测量单位不同时，直接比较原始B系数来判断"哪个变量更重要"——这是常见的解读错误。比较相对重要性时应始终使用标准化Beta；预测实际数值时则应使用原始B（因为原始B保留了原始单位，便于按情境解读）。

4. 回归假设检验

回归结果只有在满足4项主要假设时才可信——严重违反假设可能导致B系数和p值被错误估计，而不仅仅是精度下降。

假设检验方式真实结果（第2节模型）
无多重共线性每个自变量的VIF（方差膨胀因子）最高VIF = 1.02（安全阈值<5，理想值<2.5）→ ✅ 满足
误差独立Durbin-Watson（理想值接近2）DW=2.05 → ✅ 满足（2.05非常接近2）
残差（residuals）正态分布残差Shapiro-Wilk检验W=0.993, p=0.356（≥0.05）→ ✅ 满足，没有足够证据拒绝正态性
误差方差齐性（homoscedasticity）绘制残差对预测值的散点图，寻找喇叭形见下方图形——未见明显喇叭形 → ✅ 满足
方差膨胀因子（VIF）
VIF(Xᵢ) = 1 / (1 − R²ᵢ)
  • R²ᵢ用模型中所有其他自变量来回归Xᵢ本身所得到的R²——R²ᵢ越高，说明Xᵢ与其他变量的信息越"重复"
  • VIF过高（通常按惯例>5或>10）→ 存在严重多重共线性，B系数变得不稳定（增删一个观测值就会大幅波动）
为什么多重共线性很危险？如果2个自变量几乎测量同一件事（例如两道内容几乎相同的题目），模型就无法"判断"该把影响归因于哪个变量——两者的B系数都可能变得没有意义（甚至出现不符合逻辑的符号反转），即使整体模型指标（R²、F）看起来仍然正常。这正是为什么在解读每个单独的B系数之前，必须先检查VIF。

5. SPSS/PSPP实操练习

🖱️ SPSS鼠标操作步骤：

0. 首先清理study_hours的离群值（与第04/05/08单元相同）：

  1. Transform → Compute Variable... → 目标变量=study_hours，数值表达式=study_hours / 10 → If... → 条件study_hours > 20 → OK。

A. 多元回归：

  1. File → Open → Data... → 选择lop_hoc_240.sav。
  2. Analyze → Regression → Linear...
  3. 将math放入Dependent框；将study_hours、h1、a1放入Independent(s)框。
  4. 点击Statistics... → 额外勾选Collinearity diagnostics（以获得VIF）和Durbin-Watson → Continue。
  5. 点击Plots... → 将*ZRESID（标准化残差）放入Y轴，*ZPRED（标准化预测值）放入X轴 → 额外勾选Histogram → Continue → OK。
  6. 阅读"Model Summary"表（R²、调整后R²、Durbin-Watson）、"ANOVA"表（整体F、p）、"Coefficients"表（各变量的B、Beta、t、p、VIF）。

对应的PSPP语法（已验证与SPSS/Python结果完全一致——见pspp/09_hoi_quy_zh.sps）：

GET FILE='lop_hoc_240.sav'.
DO IF (study_hours > 20).
COMPUTE study_hours = study_hours / 10.
END IF.
EXECUTE.
REGRESSION
  /DEPENDENT math
  /METHOD=ENTER study_hours h1 a1.

* 已验证B=2.49/2.15/-2.68与Python结果完全一致。

📜 理论背景

线性回归起源于19世纪末Francis Galton对父子身高关系的研究（他称之为"向平庸回归"——非常高的父亲，其子女的身高往往会比父亲矮一些，向平均值"回归"）。Karl Pearson随后用严谨的数学形式将其公式化，与第08单元学到的相关系数r基于同一套数学基础——这正是为什么简单回归的R²总是等于这两个变量之间Pearson相关系数的r²。
