1. 探索性因子分析（Exploratory Factor Analysis — EFA）

EFA回答的问题是：一组众多可观测变量（调查问题、题项）能否归纳为少数几个潜在因子（latent factor/construct）——以及哪个变量"属于"哪个潜在因子？

运行EFA前——2项必做的检验：
检验回答什么问题真实结果（h1-h3, a1-a3, n=237）
KMO（Kaiser-Meyer-Olkin）数据是否有足够的共同相关性，"值得"归纳为因子？（0-1，越高越好）KMO=0.688（"尚可"水平——可接受，但不算优秀）
Bartlett球形检验各变量之间的相关矩阵是否与单位矩阵（identity matrix，即变量完全不相关）存在显著差异？χ²=313.28，p<0.001 → 显著，满足进行EFA的条件
因子载荷（factor loading）
λᵢⱼ = 可观测变量i与潜在因子j之间的相关性
  • λᵢⱼ取值范围为−1到1，类似相关系数——|λ|≥0.4或≥0.5通常被视为在该因子上"明显载荷"（具体阈值因学科而异）
  • 共同度（Communality, h²）一个变量在所有因子上载荷的平方和——该变量的变异中被因子"解释"的百分比
真实数据——2因子EFA，Varimax旋转（n=237）：
变量因子1因子2
h1（兴趣）−0.0430.747
h2（兴趣）−0.0030.603
h3（兴趣）−0.0960.670
a1（焦虑）0.725−0.092
a2（焦虑）0.722−0.083
a3（焦虑）0.695−0.016
特征值：因子1=2.21，因子2=1.73（均>1，符合Kaiser准则）。总解释方差≈65.7%。EFA"重新发现"了用于生成该数据集的2个潜在概念（兴趣/interest，焦虑/anxiety）——确认该方法运作正确：h1-h3明显载荷在一个因子上，a1-a3明显载荷在另一个因子上，没有混淆。
PCA（主成分分析）与EFA（因子分析）并非同一种技术，尽管常被混淆。PCA（SPSS/PSPP默认称为EXTRACTION=PC）寻找能够解释最大观测方差的线性组合——不区分各变量的"共同"方差与"独有"（误差）方差。"真正的"EFA（主轴法、最大似然法等）只对共同方差建模，假设每个变量都有各自独立的测量误差——更接近"潜在概念"这一理念。对于像本例这样结构清晰的数据，两者结果相近；对于结构不够清晰的数据，选错技术可能导致不同的结论。

2. 聚类分析（Cluster Analysis）

聚类分析回答的是与EFA完全不同的问题：聚类不是将"变量"分组，而是将观测"对象"（此处为195所学校）按照在多个变量上相似的"画像"（profile）分为若干组。

容易混淆的陷阱："因子分析"与"聚类分析"听起来相似（都是把某种东西"分组"），但分组"对象"与分组"变量"完全不同。EFA回答"哪些题项测量了同一概念？"；Cluster回答"哪些学校的画像相似？"。

真实数据——基于5个WLE指标（EDULEAD, NEGSCLIM, STAFFSHORT, EDUSHORT, DIGPREP）的K均值聚类，已z-score标准化，n=195：

若纯粹按轮廓系数判断（衡量聚类间分离程度，越接近1越好），k=2是最优选择。但k=3给出了更具解释力的故事——这是统计最优与可解释性之间的经典权衡。

0（n=64）+1.42−0.62−0.62−0.68+1.22领导力强、困难较少、数字化准备度高

轮廓系数（衡量聚类质量）
s(i) = (b(i) − a(i)) / max(a(i), b(i))
  • a(i)点i到同一聚类中其他点的平均距离
  • b(i)点i到最近的其他聚类中各点的平均距离
  • s(i)取值范围为−1到1；接近1=聚类效果好（离自己所属聚类近、离其他聚类远）；接近0=边界模糊；为负=可能被错误分配到该聚类
真实验证：PSPP（QUICK CLUSTER）与Python（scikit-learn KMeans）在相同数据、相同k=3下，给出了不同的聚类大小！ PSPP：37/128/30。Python：64/49/82。这并非错误——K均值对初始质心（initial centroids）非常敏感，而两款软件采用了不同的初始化策略。这正是为什么好的实践是用不同的随机初始点多次运行K均值（Python默认n_init=10——运行10次，取最优结果）后再相信最终结果，而不是只运行一次就把它当作"真相"。

3. SEM与多层次模型（Multilevel Modeling）入门

SEM（结构方程模型，Structural Equation Modeling）将EFA的思路（潜在变量由多个可观测变量测量）与回归（第09单元）的思路结合在同一个模型中——可以同时检验"这些题项是否真正测量了预期的潜在概念"（测量部分）以及"潜在概念之间假设的因果关系如何"（结构部分）。这是一项高级技术，需要专用软件（AMOS, Mplus, R中的lavaan）——基础版PSPP和SPSS均不支持。

为什么PISA数据需要多层次（multilevel/HLM）模型，而不能只用普通回归？ PISA数据集中的7,368名学生嵌套于195所学校之中——同一所学校的学生通常比不同学校的学生更相似（同样的教师、同样的设施）。普通回归（第09单元）假设各观测之间相互独立——当数据具有嵌套（nested）结构时，该假设被违反，导致标准误（SE）被低估，容易错误地得出"具有统计显著性"的结论（Type I error增加）。多层次模型分别对学生层面和学校层面的方差进行建模，正确处理这种嵌套结构。

SEM与多层次模型超出了本课程直接计算的范围（需要基础SPSS/PSPP之外的专用软件/程序包）——本节仅介绍概念，并指出哪些数据情境（如PISA）需要考虑使用它们。

4. SPSS/PSPP实践

🖱️ SPSS操作步骤：

A. 因子分析（EFA）：

  1. File → Open → Data... → 选择lop_hoc_240.sav。
  2. Analyze → Dimension Reduction → Factor...
  3. 将h1, h2, h3, a1, a2, a3移入Variables框。
  4. 点击Descriptives... → 勾选KMO and Bartlett's test of sphericity → Continue。
  5. 点击Extraction... → 选择Fixed number of factors=2 → Continue。
  6. 点击Rotation... → 选择Varimax → Continue → OK。

B. 聚类分析（K均值）：

  1. 打开vnm_truong_195_tong_hop.sav。
  2. Analyze → Classify → K-Means Cluster...
  3. 将EDULEAD, NEGSCLIM, STAFFSHORT, EDUSHORT, DIGPREP移入Variables框，将Number of Clusters设为3。
  4. 点击OK——查看"Final Cluster Centers"和"Number of Cases in each Cluster"表格。

PSPP等效语法（已验证可运行——见pspp/10_nhan_to_cum_zh.sps）：

FACTOR VARIABLES=h1 h2 h3 a1 a2 a3
  /EXTRACTION=PC
  /CRITERIA=FACTORS(2)
  /ROTATION=VARIMAX.

QUICK CLUSTER EDULEAD NEGSCLIM STAFFSHORT EDUSHORT DIGPREP
  /CRITERIA CLUSTER(3)
  /PRINT INITIAL.
* 注：PSPP使用EXTRACTION=PC（主成分法），与Python中常用的
* "主轴因子法"不同——结论定性上相同（同样的2组变量），但载荷
* 数值不完全一致。QUICK CLUSTER与Python得到不同的聚类大小，
* 是由于K均值初始化策略不同所致（见第2节的提示）。
