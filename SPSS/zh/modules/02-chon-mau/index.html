2·简单随机与系统抽样

每个单位被抽中的机会都相等

简单随机：从整个抽样框架中随机抽取。

系统抽样：每隔k个单位抽取一次（如名单中每第10名学生）。

分层抽样

先分组，再在每组内随机抽样

按相关特征（地区、学校类型）将抽样框架分层，确保每一层都按比例出现在样本中。

PISA正是这样做的——先按地区分层，再抽取学校。

整群与多阶段

整群抽取，而非逐个抽取个体

随机抽取学校（群），再测量其中全部或部分学生——比在全国范围内随机抽取分散的学生个体便宜得多。

PISA：第一阶段抽取学校（群），第二阶段在校内抽取学生——即"多阶段"。

3·四种常见类型

方便抽样：选取最容易接触到的对象。目的性抽样：按既定标准选取。

配额抽样：按组凑足数量，组内不随机。滚雪球抽样：由参与者互相介绍。

常见错误：使用非概率抽样，却仍然用统计方法推论到整个总体。

4·抽样误差

样本与总体之间的自然差异

即使抽样完全正确（正确随机化），样本仍会因偶然性而与总体略有不同——这是抽样误差，不同于抽样偏误（bias，由抽样过程本身存在问题导致）。

1. 总体、抽样框架与样本

三个常被混淆的概念，抽样前必须先区分清楚：总体（population）是理论上想要推论到的全部群体；抽样框架（sampling frame）是可以从中实际抽样的真实名单；样本（sample）是实际被测量的子集。

覆盖误差（coverage error）：抽样框架与真实总体之间的差距。例如：PISA的抽样框架只包含已报名参加调查的学校——如果偏远地区学校报名率较低，即使框架内的抽样完全随机且执行正确，样本仍可能存在偏差。
层次在越南PISA 2025例子中
总体越南全部15岁学生
抽样框架教育培训部提供给经合组织的学校名单
样本195所同意参加的学校，7,368名学生被测量

2. 概率抽样（probability sampling）

定义性特征：每个单位被抽中的概率必须是可确定的（不必相等）。这是能够对总体进行有效统计推论的必要条件。

类型做法优点缺点
简单随机对整个抽样框架随机化简单，若框架良好则无偏需要完整框架；地理分散时成本高
系统抽样按名单每隔k个单位抽取一次易于执行，在名单上均匀分布若名单存在与k吻合的隐藏周期则有风险
分层抽样按相关特征划分框架，在每层内随机抽样确保每个重要群体按比例出现，降低误差需要事先了解该特征
整群／多阶段先抽取整个群（如学校），再在群内抽样后勤成本低得多相同样本量下精度不如简单随机抽样
PISA同时使用两者：先按5个地区分层，再在每个地区内按与学校规模成比例的概率进行整群抽样（学校）——正是"分层多阶段整群抽样"。

3. 非概率抽样（non-probability sampling）

定义性特征：每个单位被抽中的概率无法确定。这并不意味着"错误"——只是意味着不应该用它来对总体做精确的统计推论。

类型做法适用情况
方便抽样选取最容易接触到的对象初步探索性研究，时间／经费严重受限
目的性抽样根据与研究问题相关的标准有意选取需要专家／典型案例，深度定性研究
配额抽样按组凑足目标数量，组内不随机需要按比例分组但缺乏完整框架
滚雪球抽样参与者介绍下一位稀少、隐蔽、难以接触的群体
常见错误：使用方便抽样（如仅调查自己所教的班级），却仍然把结论写得像适用于"学生总体"一样。使用非概率抽样时，必须清楚说明推广性方面的局限。

4. 抽样误差与有科学依据的样本量

抽样误差（sampling error）是样本与总体之间因偶然性产生的自然差异——即使抽样完全正确也依然存在。不同于抽样偏误（sampling bias），后者反映抽样过程本身存在系统性缺陷。

预试样本量（Julious，2005，Pharmaceutical Statistics）：每组至少12个观测值——低于此数值，估计出的标准差之标准误波动过大（超出真实值的±20%），不足以作为下方正式样本量公式的可靠输入。

每组样本量的近似公式（Cohen，1988）：

每组样本量——独立t检验
n ≈ (zα/2 + zβ)² × 2 / d²
  • n每组所需样本量
  • zα/2对应显著性水平α的临界值——α=0.05时z=1.96
  • zβ对应β=1−检验力的临界值——检验力=0.80时z=0.84
  • d预期效应量（来自文献综述或预试）
效应量d水平每组样本量
0.2小≈394
0.5中≈64
0.8大≈26

5. 应用于真实数据：PISA样本权重

由于PISA按与学校规模成比例的概率进行整群抽样，各学校在分析时的"权重"并不相等——大学校在真实总体中代表的学生数量比小学校更多。W_NRASCHBWT变量正是用来修正这一点的。

🖱️ 用真实SPSS/PSPP验证——加权如何改变结果：

  2. Analyze → Descriptive Statistics → Descriptives... → 将EDULEAD送入 → OK（尚未加权）。
  3. Data → Weight Cases... → 选择Weight cases by → 将W_NRASCHBWT送入 → OK。
  4. 重新运行第2步——比较两次结果。
真实结果（已用PSPP验证）：未加权的EDULEAD平均数=0.7653（N=195所学校，每所计为1）。加权后平均数=0.7874（有效N=7,284.6，反映真实学生人数）。权重范围从1.0到617.2——意味着权重最高的学校所代表的学生数量是权重最低学校的617倍。在本例中忽略权重对结论影响不大（相差0.02），但对于与学校规模相关性更强的变量，误差可能大得多。

📜 理论背景与历史

现代抽样理论可追溯到耶日·奈曼（Jerzy Neyman）1934年的研究，他首次严谨地证明了为什么概率抽样（而非当时流行的凭主观判断的"代表性抽样"）才能客观地计算抽样误差——为现代推论统计奠定了基础。威廉·科克伦（William G. Cochran）的教材《Sampling Techniques》（1953年）系统化了分层与整群抽样技术，这些技术至今仍原封不动地被使用，包括在PISA的设计中。

时间线
  • 1895年——安德斯·基尔（挪威）提出"代表性方法"，是抽样的早期雏形。
  • 1934年——耶日·奈曼证明了概率抽样与最优分层的数学基础。
  • 1953年——威廉·科克伦出版《Sampling Techniques》，系统化整群／多阶段抽样理论。
  • 2000年至今——经合组织在80多个国家的PISA中采用分层＋整群＋多阶段设计。

🔎 真实案例研究

为什么PISA不对全体学生进行简单随机抽样？

面对一个国家内数百万分散的15岁学生，简单随机抽样会抽中分布在成千上万所不同学校的学生——调查团队将不得不奔赴每一所学校，仅为测量1-2名学生，后勤成本完全不可行。按学校进行整群抽样，是用一部分统计精度换取现实中的可行性——这正是PISA样本（7,368名学生）远大于理论上完美简单随机抽样所需样本量的原因。

样本权重——分析真实数据时为何不能忽略

在上述例子中，加权与未加权平均数之间的差距只有0.02——相当小，因为EDULEAD与学校规模的相关性并不强。但对于与学校规模相关性更强的变量（如设施条件、教师数量），忽略权重可能会显著扭曲结论——这正是经合组织所有官方PISA报告在公布任何数字之前都必须先加权的原因。
