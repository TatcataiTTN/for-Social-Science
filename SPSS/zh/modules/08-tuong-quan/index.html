（节选自表40.13，第765页——Cohen等人建议以斯皮尔曼和皮尔逊作为两种主要的相关统计方法。）

2. 皮尔逊 r：方向、强度与含义

相关系数 r 的范围是 −1 到 +1。符号（+/−）表示方向：同向增减为正，反向为负。|r| 的大小表示强度——r 本身就是效应量，无需另外计算（第767页）。

经典陷阱——相关不等于因果（第768页）：“手大与脚大相关”并不意味着手大导致脚大。两者更可能都与第三个变量（整体体型）有关。务必自问：是否存在能同时解释两者的第三变量？

真实数据示例（班级数据，n=240）

按照书中示范的报告方式（第768页）："使用皮尔逊相关，发现自学时长与数学成绩之间存在大效应量（r = 0.58）且具有统计显著性的相关（p < 0.001）。自学时间越长的学生数学成绩往往越高。"——但不能写成"自学时长提高了成绩"（这是观察性数据）。

3. 当关系不是直线时

皮尔逊 r 假设关系是线性的。Cohen等人的例子（第769页）：适度压力有助于集中注意力（正相关），压力过大则降低表现（负相关）——呈倒U形，而非直线。若对整个数据范围计算皮尔逊r，即使存在非常明显的关系，结果也可能接近于零，因为正、负两部分在单一系数中相互抵消。在相信r值之前，务必先绘制散点图。

4. 偏相关

当怀疑第三个变量"混入"两个主要变量之间的关系时使用。书中的例子（第770页）：篮球经验与表现之间的相关可能受身高的混淆影响——偏相关剔除身高的影响，以揭示两个主要变量之间的"真实"关系。

在越南PISA真实数据上尝试（195所学校）

学习材料短缺（EDUSHORT）与学校科学平均成绩之间的零阶相关：r = −0.039（非常弱）。怀疑的混淆变量：人员短缺（STAFFSHORT），它与学习材料短缺的相关较高（r=0.61）——类似于篮球例子中的“身高”。在控制人员短缺后，偏相关为：r = −0.051——几乎没有变化。

为什么与书中的例子不同？只有当控制变量与另外两个变量都存在真实关联时，偏相关才会发生明显变化。这里，人员短缺与科学成绩几乎无关（r≈0.002）——因此"剔除"它对原始结果影响甚微。这是真实的结果，并非每份数据都能像教材例子那样呈现戏剧性的变化。

📜 理论与历史背景

"相关"这一概念源于一个非常具体的问题：1888年，高尔顿（Francis Galton，达尔文的表弟）研究子女身高与父母身高相似的程度。他将这一现象称为"co-relation"（共变关系）。高尔顿一个引人注目的发现是：身材非常高的父母，其子女往往略矮于父母（更接近总体平均水平）——他称之为"向平均数回归"（regression toward the mean），这同时为相关和回归（第9单元）奠定了基础。

八年后的1896年，统计学家卡尔·皮尔逊（Karl Pearson）——高尔顿的学生——将"co-relation"的想法形式化为你今天在SPSS中使用的精确数学公式：皮尔逊积矩相关系数，也就是"皮尔逊r"这一名称的由来。1904年，心理学家查尔斯·斯皮尔曼（Charles Spearman）开发出适用于排秩数据（无需正态分布假设）的版本——成为本单元学到的斯皮尔曼rho。

与本单元相关的时间线
  • 1888年——高尔顿研究身高遗传，提出"co-relation"一词，并发现"向平均数回归"现象。
  • 1896年——卡尔·皮尔逊将积矩相关公式形式化——"皮尔逊r"诞生。
  • 1904年——查尔斯·斯皮尔曼提出等级相关系数——"斯皮尔曼rho"。
  • 今天——泰勒·维根（Tyler Vigen）的网站tylervigen.com/spurious-correlations收录了数百对纯属巧合却高度相关的变量，被广泛用于教学中说明"相关不等于因果"。

🔎 真实案例研究

案例1——高尔顿最初的身高数据

高尔顿测量了数百对父母与子女的身高。他绘制了散点图（正是你在第3单元学到、在此再次使用的图表类型），发现这些点形成一个倾斜的椭圆形云团——不是完美的直线，但有明显的趋势。正是从这一云团的形状出发，他以及后来的皮尔逊设计出用单一数字来概括这种趋势的方法——这正是r系数至今仍在做的核心工作。

案例2——"伪相关"：尼古拉斯·凯奇电影与溺水事件

泰勒·维根著名的"伪相关"（Spurious Correlations）项目曾显示：尼古拉斯·凯奇每年上映的电影数量与当年美国游泳池溺水死亡人数之间存在非常高的相关（r超过0.6，某些年份接近0.9）——尽管两者显然没有任何因果联系。这是对本单元强调的"相关不等于因果"（第768页）这一教训的极端（且刻意幽默的）例证：只要变量足够多、数据年份足够长，出现高度巧合的相关在统计上并不罕见（这与原课程第6/7单元中关于p值操纵的教训相呼应）。
